## 编码与提交规范

- 所有 `.c / .h` 保存为 **UTF-8 带 BOM + CRLF**。没有 BOM 时 MSVC 按 936 代码页读取，中文注释会先报 C4819，再引发 C2449、C2059 这类"文件范围内找到 `{`"的莫名编译错误。
- 提交信息：`dayNN: 主题`、`chore: ...`、`docs: ...`、`fix: ...`。
- 不提交编译产物：`.exe / .obj / .pdb`、`Debug/`、`Release/`、`.vs/`（已在 `.gitignore` 中）。
