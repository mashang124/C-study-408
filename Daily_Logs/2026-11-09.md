## 一、今日知识点

1. **带头结点 vs 不带头结点**：头结点不存数据（本代码里 `data` 固定为 0），好处是插入删除时第一个位置和中间位置可以用同一套代码，不用为"改头指针"写特例。
2. **头插法**：`p->next = L->next; L->next = p;` —— 先连后断，顺序不能反。
3. **尾插法**：必须有一个能拿到尾结点的 `get_tail`，否则每次插入都要从头遍历一遍，尾插退化成 O(n)。
4. **pos 语义**：本代码统一为「pos 从 1 开始，只数数据结点，不含头结点」。`insertNode(L,1,e)` 插到最前面，`insertNode` 还允许 `pos = len+1` 追加到末尾；`deleteNode` 则要求 `1 ≤ pos ≤ len`。
5. **释放链表**：必须先把 `next` 存下来，再 `free(p)`，最后 `p = q`；顺序错了就是释放后使用。

## 二、初学者避坑指南（今天实测翻车的 3 个点）

### 坑 1：`get_tail` 从 `L->next` 开始找 → 空链表直接崩溃

```c
Node* p = L->next;        // 空链表时 p == NULL
while (p->next != NULL)   // 解引用空指针
```

实测：空链表调用 `get_tail`，进程退出码 `-1073741819`（即 `0xC0000005` 访问冲突）。

**改法**：从 `L` 开始找。空链表时会返回头结点，`insertTail(L, e)` 正好把元素插到第一个位置，一个改法同时解决两个问题。

### 坑 2：`freeList` 里释放完还写 `L->next = NULL` → 释放后使用

```c
while (p != NULL) { q = p->next; free(p); p = q; }
L->next = NULL;   // L 已经在上面的循环里被 free 掉了
```

而且 `main` 里紧接着又调 `listLength(list)` —— 读的是已释放内存。原程序最后打印的那个 `1` 就是这次未定义行为制造的"假象"，不是真实长度（真实是 4）。

**改法**：签名改成 `void freeList(Node** L)`，循环里不要碰 `*L`，最后统一 `*L = NULL;`，调用方写 `freeList(&list)`。这样"释放完把指针置空"这件事由函数自己保证，不会留下野指针。

### 坑 3：`listLength` 从 `L` 开始数 → 头结点被算进长度

链表里 4 个元素，函数返回 5。**改法**：从 `L->next` 开始数。

## 三、双语注释代码段

修复后的尾插与释放：

```c
/* Find the tail node and return it.
 * Start from L (the dummy head), not L->next: for an empty list this
 * returns the head itself, so insertTail still has a valid target.
 * 从头结点开始找，空链表时返回头结点，保证不会解引用空指针。 */
Node* get_tail(Node* L)
{
	if (L == NULL)
	{
		return NULL;
	}
	Node* p = L;
	while (p->next != NULL)
	{
		p = p->next;
	}
	return p;
}

/* Destroy the whole list and null out the caller's pointer.
 * Take the address of the head pointer so we can clear it after freeing;
 * 传头指针的地址，释放完把调用者的指针置空，避免野指针。 */
void freeList(Node** L)
{
	if (L == NULL || *L == NULL)
	{
		return;
	}
	Node* p = *L;
	while (p != NULL)
	{
		Node* q = p->next;   /* save next before freeing / 先存 next 再 free */
		free(p);
		p = q;
	}
	*L = NULL;
}
```
